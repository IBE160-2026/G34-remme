Slik startes appen, og hva den er laget av

For sensor

docker compose up, og så åpne 127.0.0.1:3000. Uten nøkkel starter appen i demomodus.

For utviklere

uv run fastapi dev i backend og npm run dev i frontend. Samme porter, samme app.

DelValg

Claudeanthropic-SDK · Opus 5.5
FrontendNext.js 16 · React 19 · TypeScript
UtseendeTailwind 4 · shadcn/ui · DESIGN.md
Testingpytest · Vitest · Playwright
Stacken bygger på technology.md fra Pytagoras-prosjektet, men bare det en liten lokal app trenger. Database, Redis, Railway, innlogging og betaling er tatt bort. Alle versjoner er sjekket mot npm og PyPI.
