Demomodus og tester bruker samme vei

Demomodus
Uten nøkkel bruker backenden lagrede eksempelsvar. Eksemplet har ett krav av hver status og ett oppdiktet sitat, så sensor ser også sitatkontrollen i arbeid.
pytest
Kjernen og analysen testes mot lagrede svar, også ugyldige. Testene stoppes hvis de prøver å kalle Claude.
Vitest
Komponenter, meldinger og tegntelling.
Playwright
Hele flyten i demomodus, med tilgjengelighetssjekk (axe).
Testsettet
5 annonser og 3 fiktive CV-er kjøres manuelt mot ekte Claude, og resultatet noteres.
Ingen automatiske tester går mot nettet. Det gjør dem gratis og gir samme svar hver gang, som PRD-en krever.
