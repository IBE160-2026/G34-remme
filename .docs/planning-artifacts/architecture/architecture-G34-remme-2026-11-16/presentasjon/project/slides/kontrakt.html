Tre endepunkter og faste utfall

EndepunktSvar
GET /api/statusEr appen i demomodus, og hva er tegngrensen?
GET /api/exampleEksempel-CV og eksempelannonse (bare i demomodus)
POST /api/analyzeEt resultat, eller ett av fem utfall: tomt felt, for lang tekst, krever nøkkel, ingen krav, eller feil i analysen

Backenden beskriver svaret med Pydantic. Frontendens typer genereres fra dette og skrives aldri for hånd. Frontenden eier alle norske meldinger.

Utfall sendes som data, ikke som HTTP-feil. Alt frontenden ikke forstår, som nettverksfeil og tidsavbrudd, vises som «Klarte ikke å analysere, prøv igjen».
